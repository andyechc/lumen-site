# Lumen - Sistema Solar

Un sitio web hermoso y minimalista sobre el Sistema Solar.

## Sobre

Lumen es un sitio dedicado a explorar y aprender sobre nuestro sistema solar. Un viaje visual a través de los planetas.

## Despliegue

Este sitio está desplegado en GitHub Pages. Cada push a la rama `main` desencadena el despliegue automático.

## Tecnologías

- HTML5
- CSS3
- GitHub Pages
